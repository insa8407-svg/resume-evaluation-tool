# resume-evaluation-tool
AI-based Resume Score Analyzer using Python and Streamlit to evaluate resumes and provide scoring and improvement suggestions.
# Resume Score Analyzer

## 📌 Overview
This project analyzes resumes and provides a score based on key factors such as skills, keywords, experience, and formatting. It helps users understand how well their resume matches job requirements.

## 🎯 Objective
To build an intelligent system that evaluates resumes and gives feedback to improve job selection chances.

## ⚙️ Technologies Used
- Python
- Streamlit (UI)
- Natural Language Processing (NLP)
- Pandas
- Scikit-learn (optional)

## 📊 Features
- Upload resume (PDF/Text)
- Extract text from resume
- Keyword matching with job description
- Resume scoring system
- Suggestions for improvement
- Interactive UI dashboard

## 🧠 Methodology
- Text extraction from resume files
- Preprocessing (tokenization, stopword removal)
- Keyword matching and scoring
- Simple NLP techniques to evaluate relevance

## 📈 Output
- Resume score (percentage)
- Missing keywords
- Improvement suggestions
- Visual feedback

## 🚀 How to Run
```bash
streamlit run app.py
